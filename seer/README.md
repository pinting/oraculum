# seer

## Setup

### Interactive mode

Only requires [Rust](https://rustup.rs).

```bash
cargo run
```

### Constraining a llama.cpp model

Requires [Rust](https://rustup.rs) and [UV](https://docs.astral.sh/uv/getting-started/installation).

```bash
make build
source .venv/bin/activate
python main.py
```
